# Tuiminal 0.2.0-alpha.0

Tuiminal now starts with a minimal installation and downloads its official tools
when you select them. Database, Git, Runner, HTTP, and Free Terminal remain
first-party components maintained in this repository.

```sh
npm install --global tuiminal@alpha
tuiminal
```

- Install tools from the first-launch screen or manage them from global settings.
- Read detailed descriptions and animated tool icons, and follow actual download progress.
- Open installed tools or uninstall them after confirmation. Uninstalling closes
  that tool's sessions and preserves your projects and saved configuration.
- Each download must match the version and hashes embedded in the executable.
  Payloads are stored outside your project and never run npm installation scripts.
- The development command exercises the same installation flow with local payloads.
- Internal workspace boundaries keep the host and tools on the same React/OpenTUI runtime.
- English is the canonical documentation language, with a Brazilian Portuguese README.
- HTTP discovery handles newly created directories, and truncated responses stop
  their native network transfer. GitHub mutations retain their execute-once and
  uncertain-result protections.

The npm distribution contains a Node.js launcher and native binaries for macOS,
Linux glibc, and Windows on x64 and ARM64. Node.js 22 or later is required; users
do not need to install Bun. The five official feature archives, their catalog,
the seven npm tarballs, and SHA256 checksums are attached to this release.

This is an alpha: shortcuts, formats, and behavior may change. Review
[the security policy](https://github.com/DeividXupon/tuiminal/blob/main/SECURITY.md)
for supported reporting channels.
