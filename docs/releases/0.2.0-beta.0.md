# Tuiminal 0.2.0-beta.0

The first Tuiminal beta brings the workspace improvements developed since
`0.2.0-alpha.0` to all six native platforms.

```sh
npm install --global tuiminal@beta
tuiminal
```

- Shared action palettes, spatial panel selection, a redesigned settings center,
  and a mouse pointer with an ASCII particle trail improve workspace navigation.
  macOS Option-number shortcuts are recognized alongside Alt-number shortcuts.
- Term Agents adds persistent agent-aware workspaces, Live Diff with bundled
  offline syntax grammars, searchable recent sessions, and public message and
  activity history for Codex, Claude Code, and OpenCode integrations.
- Remote agent workflows include guided SSH setup, resumable sessions, and
  incremental project synchronization with progress reporting and preserved
  file and directory metadata.
- Git adds PR and issue creation workflows, branch pickers, configurable browser
  selection, unified action palettes, and paginated conversations.
- Runner adds an integrated YAML editor, saved flows, action palettes, execution
  status panels, and a guided tutorial.
- HTTP adds Postman workspaces and linked collections, unified environments,
  keyboard and mouse collection management, faster response navigation, and
  copying of the complete captured response.
- Database adds external connection-profile discovery, sliding result windows,
  SQL read previews, action palettes, and spatial panel selection.
- Dependency updates, expanded performance benchmarks, lifecycle fixes, and
  refreshed documentation and demos accompany these changes.

The npm distribution contains the `tuiminal` launcher and six native packages for
macOS, Linux glibc, and Windows on x64 and ARM64. Node.js 22 or later is required;
users do not need to install Bun. Database, Git, Runner, HTTP, and Term Agents
remain official tools downloaded on demand with version and integrity checks.
The five feature archives, their catalog, all seven npm tarballs, the publication
manifest, and SHA256 checksums are attached to this release.

This release uses the npm `beta` channel. The existing `alpha` and `latest`
channels remain unchanged. Shortcuts, formats, and behavior may still change
during beta. Report issues through
[GitHub Issues](https://github.com/DeividXupon/tuiminal/issues) and follow
[the security policy](https://github.com/DeividXupon/tuiminal/blob/main/SECURITY.md)
for private vulnerability reports.
